# Hi, I'm Kai.

**AI Product Manager · Content Creator · Long-term Builder**

> 不要温顺地走入那个 AGI 良夜。

我在新闻、设计、能源产业和 AI 之间工作。做过新华社的新闻与内容，也在中国石化宁夏一线理解真实业务；这些经历最终汇入现在的方向：把 AI 变成能在真实世界里使用的产品。

我喜欢把不同世界连接起来：新闻训练给了我观察与叙事，设计经历让我关注体验，产业现场让我尊重现实，而 AI 正在打开新的产品可能。

## What I'm up to

- 探索 AI 如何进入真实业务，而不只是停留在演示里
- 搭建 AI workflows，实践 Prompt Engineering、ComfyUI 与 Vibe Coding
- 研究文学、电影、科幻叙事与产品语言之间的关系
- 沿着 **酒 × 内容 × AI** 三条主线，积累长期作品

## Things I work with

`AI Product` · `Figma` · `AI Workflows` · `Prompt Engineering` · `Vibe Coding` · `Visual Storytelling`
